# DailySmart AI

AI-powered Smart Dairy Cooperative Management System.

DailySmart AI uses dairy data to provide milk production forecasting,
early warnings, farmer intelligence and data-driven recommendations.

## Technologies
- HTML
- CSS
- JavaScript
- Chart.js
- IBM Bob

## Key Features
- Smart Milk Collection Management
- AI Milk Production Forecast
- Smart Early Warning System
- AI Farmer Intelligence
- Demand and Supply Analysis
- Farmer Performance Analysis
